Theoretical Formulations & Approximation Proofs

1. Branch and Bound (Reduced Cost Matrix Method) Exact Optimal: O(N!)

The Branch and Bound algorithm constructs a state-space tree of candidate partial routes. At each node, a lower bound on the completion cost of any tour starting with that prefix is computed using matrix reduction (Little et al.):

Lower Bound L = L_parent + cost(u, v) + ∑ row_min(reduced) + ∑ col_min(reduced)
  • Row & Column Reduction: Subtracting row/column minimums preserves the relative ordering of tours while extracting a guaranteed lower bound.
  • Pruning Criterion: Any partial path with bound ≥ best_cost is immediately pruned, eliminating large swaths of the factorial search space.

2. Christofides-Serdyukov Algorithm Factor ≤ 1.5: O(N³)

Christofides' algorithm guarantees a solution within 1.5× OPT for Metric TSP (where the triangle inequality holds: d(i,k) ≤ d(i,j) + d(j,k)):

  1. MST Construction: Compute Minimum Spanning Tree $T$ ($cost(T) \le OPT$).
  2. Odd Degree Set $O$: Find vertices with odd degrees in $T$. By the Handshaking Lemma, $|O|$ is even.
  3. Minimum Weight Perfect Matching $M$: Match vertices of $O$ such that $cost(M) \le 0.5 \times OPT$.
  4. Eulerian Multigraph $H = T \cup M$: Every vertex now has even degree, guaranteeing an Eulerian circuit.
  5. Shortcutting: Traverse the circuit, shortcutting already visited vertices:
    cost(Tour) ≤ cost(T) + cost(M) ≤ OPT + 0.5 OPT = 1.5 × OPT

3. 2-Approximation Algorithm (MST Doubling) Factor ≤ 2.0: O(N²)

Doubling the edges of an MST $T$ yields a connected multigraph where all degrees are even. The Eulerian tour has total cost $2 \times cost(T) \le 2 \times OPT$. Shortcutting via preorder DFS guarantees:

cost(Tour_MST) ≤ 2 × cost(T) ≤ 2.0 × OPT

4. 2-Opt Local Search Improvement Polynomial Local Search: O(N²)

Takes an initial approximation tour and repeatedly tests pairs of edges $(u_1, u_2)$ and $(v_1, v_2)$. If reversing the intermediate subpath reduces total distance, the 2-exchange is executed. In practice, this brings Christofides tours to within 0% to 3% of exact optimality.
